## Announcement 2 — What the Protocol Does

A2A Protocol fills the gap between AI capability and economic participation.

Today's agents can reason. They can plan. But they cannot:
→ Enter binding agreements
→ Hold funds until delivery is confirmed
→ Settle without a trusted intermediary

A2A Protocol gives them that infrastructure.

---

## Announcement 3 — How It Works

The flow:
1. User defines a task (budget, deadline, description)
2. Buyer agent + seller agent negotiate via LLM reasoning
3. Terms locked in Soroban escrow on Stellar
4. Verifier agent confirms delivery
5. Payment releases automatically

Every decision is logged. Every step is auditable. No platform in the middle.
